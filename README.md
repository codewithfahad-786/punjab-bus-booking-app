# 🚌 Punjab Bus Booking App

A professional Streamlit web application to calculate bus booking prices for Punjab, Pakistan routes. 
This app predicts the final booking price based on distance, fuel price, and estimated trip cost.

## ✨ Features

- **Route Selection**: Choose From and To cities from Punjab
- **Distance & Fuel Input**: Enter KM and current fuel price
- **Trip Cost Calculation**: Auto calculates fuel, maintenance, and other charges
- **Final Price Prediction**: ML model + 40% profit margin included
- **Clean UI**: Logo, form-based input, and professional summary

## 🛠️ Tech Stack

- **Frontend**: Streamlit
- **Backend**: Python, Pandas, NumPy
- **ML Model**: Scikit-learn, Joblib
- **Data**: punjab.csv
